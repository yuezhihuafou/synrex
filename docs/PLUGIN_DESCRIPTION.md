# Synrex — ChatGPT plugin descriptions

## Recommended short description (English)

Self-hosted coding and execution for ChatGPT. Read and edit project files, run
builds and tests, inspect Git changes, manage durable tasks and multi-host
workspaces, and enforce project architecture boundaries. GPT remains the
reasoning agent; Synrex provides the tools and verifiable execution state.

## One-line tagline

Synrex — Governed execution for AI.

## Longer product description (English)

Synrex is a GPT-first, self-hosted coding and execution harness. It connects
conversational AI to real project workspaces with efficient context and tool
responses, code editing, semantic navigation, Git reviews, shell execution,
durable commands, resumable workflow checkpoints, and optional multi-host
execution. Project instructions and architecture checks help keep iterative
changes within approved boundaries. Synrex does not replace GPT's reasoning,
guarantee model continuation after a chat ends, or bundle Research Harness.

## Scope and compatibility

This is public-facing plugin copy, not an instruction to change OAuth client
IDs, MCP URL, existing ChatGPT installation identity, legacy CLI commands,
database filenames, or deployment paths. ChatGPT's installed plugin listing
and description may require a user-side edit or reconnection; publishing a
server description does not remotely edit a preexisting client snapshot.
