# Synrex v0.4.4 — first-use and Windows deployment reliability

This patch addresses the problems observed during a real Windows first-time
deployment. The original public MCP URL, OAuth identity, SQLite state and
installation owner remain unchanged.

## Changes

- Uses arrow keys and Enter for a single ChatGPT / Coding Agents / Both choice,
  with explicit Space instructions only for genuine multi-selection.
- Skips irrelevant Coding Agents setup when only ChatGPT is selected.
- Adds `synrex config roots list|add|remove` to avoid repeated
  `init --force` for normal project changes. The initial Windows
  flow favors a dedicated D: project root when present and asks before
  creating new directories.
- Adds `synrex doctor --connect` with read-only local MCP, public
  MCP and OAuth metadata checks, explaining expected 401 Bearer, missing DNS
  routes, origin 502 and authorization interception.
- Improves the existing Windows portable Task Scheduler generator: silent
  startup, separate bounded logs, repeat-on-failure policy, single-instance
  policy, and Unicode-safe script encoding.
- Extends native Windows acceptance with generated script syntax, project
  management and task registration/startup checks.

## Upgrade / rollback

- Stage and activate the official v0.4.4 archive with the portable installer;
  the previous version remains available for explicit `--rollback`.
- The installer never replaces an existing scheduled task, Cloudflare Tunnel,
  Owner secret or OAuth store. Generate and inspect new task definitions
  before registering; old customized scripts are not silently overwritten.
- Windows task autostart is user-login based, not a pre-login SYSTEM service.
- Production activation remains separately gated by real authenticated MCP
  verification, backup and rollback.

Availability requires an annotated v0.4.4 tag, a successful exact-commit
main CI run and a published GitHub archive/checksums. Notes alone do not
prove publication.
