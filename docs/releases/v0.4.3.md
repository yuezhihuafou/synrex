# Synrex v0.4.3 — Windows silent startup and tunnel recovery

This patch integrates the verified tunnel recovery change and makes newly
generated Windows portable autostart tasks launch without a visible console.

## Changes

- A bounded Cloudflare tunnel watchdog can request nonblocking recovery after
  repeated zero-HA samples even when the WAN probe is unavailable. It does not
  infer tunnel recovery from a successful restart request.
- Newly generated `Synrex.Portable` Windows Task Scheduler definitions use
  `wscript.exe` with a generated hidden launcher, avoiding a transient
  interactive PowerShell or Node console. Generation remains opt-in and
  refuses to replace existing service definitions.
- Existing standalone operational tasks `Synrex.WinDirect` and
  `Synrex.SwyPublicMonitor` remain separate, user-managed installations.
  Updating the official portable package intentionally does not overwrite
  those scheduled tasks, addresses or OAuth configuration.

## Compatibility and rollback

- CLI, OAuth identity, SQLite state, tool contracts and installation prefix
  remain compatible with v0.4.2.
- The optional Windows startup script is a newly generated artifact; running
  the release installer alone does not register or start it.
- Use the portable installer to stage and explicitly activate v0.4.3; prior
  versions remain available for `--rollback`.
- swy1 production promotion is separately gated by the immutable main
  release, backup, tests and its existing rollback procedure.

Release availability requires a verified annotated `v0.4.3` tag, CI-successful
source commit and published GitHub archive/checksums. This note alone is not
evidence that publication has completed.
