01 /WHAT IT SOLVES

Built for the work between prompts.

Not another chat interface. A reliable execution layer for the messy, multi-step work that happens in real repositories.

01 / CONTINUITY ↗

Long-running work, without losing the thread.

Commands can outlive an individual MCP response. Durable task IDs, checkpoints, and retrievable logs make unfinished work inspectable.

02 / EVIDENCE ⌁

Proof you can inspect.

See what changed, what ran, and what failed. Review source diffs and execution receipts instead of trusting an unverified success message.

03 / INFRASTRUCTURE ⌘

Your environment, not a remote black box.

Run against your own workspaces on a self-hosted machine. Connect optional compatible peers for distributed engineering tasks.

04 / BOUNDARIES ◇

Context with boundaries.

Workspace-scoped tools, isolated Git worktrees, architecture checks, and compact results help keep large coding tasks accountable.

02 /HOW IT WORKS

Keep the intelligence.
Own the execution.

ChatGPT remains the visible reasoning and decision-making host. Synrex provides authenticated tools, workflow state, and controlled access to your execution peers. It does not start a second hidden AI agent or promise to wake ChatGPT after a conversation ends.

03 /START BUILDING

From source to first task.

Start in a disposable repository. Linux is the primary supported environment; macOS and Windows have platform-specific limitations. Configure authentication before remote access.

SOURCE INSTALL / NODE 22.19+ / PNPM 11.25.0
git clone https://github.com/yuezhihuafou/synrex.git
cd synrex
corepack enable
corepack prepare pnpm@11.25.0 --activate
pnpm install --frozen-lockfile
pnpm build
npm link
synrex init
synrex doctor
